Useful Linux Commands

ls lists files in a directory, and cd changes the current directory.
grep searches for text inside files, and find searches for files by name.
cat prints a file, and less lets you scroll through a long file.
ps and top show running processes, and kill stops a process.
chmod changes file permissions, and ssh connects to a remote machine.

Combine commands with pipes, for example: grep error app.log | wc -l.
